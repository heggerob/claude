# Guardian

Planning repository for **Guardian** (working title "Mac Guardian") — a
provider-independent supervisor that keeps development machines, AI coding agents
and workflows running until tasks are verifiably finished.

## Documents

- [**The Grand Plan**](docs/guardian-grand-plan.md) — the current master plan:
  Mac + Windows + iPhone, screen-by-screen app designs, system architecture,
  implementation playbook and cross-platform roadmap.
- [Mac Guardian product plan](docs/mac-guardian-product-plan.md) — the original
  Mac-only product plan (superseded by the Grand Plan, kept for reference).
